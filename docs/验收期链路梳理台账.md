# 验收期链路梳理台账

## 目的与边界

本台账用于项目收尾前的全链路学习、审查与低风险精简。覆盖 `src/main/java` 下全部非测试类；不新增业务功能，不做架构重写。

仅当代码、配置、调用关系和测试共同证明改动后既有功能、异常处理、异步时序和对外结果完全不变时，才可将其列为“待批准精简”。任何不确定项均记录为“保留”，不得删除或合并。

## 每个类的记录项

1. 所属链路和文件路径。
2. 入口、调用方和下游依赖。
3. 职责与关键方法。
4. 配置、Spring Bean、线程/异步和异常边界。
5. 代码、测试、配置和 Git 历史证据。
6. 结论：保留、待批准精简或待继续核实。

## 已确认基线

- 当前验收基线为 GitHub `lcy-project` 的 `0ab8da5` 加上已验证但尚未提交的 Outbox 初始化修复。
- Outbox 表、到期索引及真实 `schema.sql` 初始化回归测试已通过定向测试和 `mvn -q -DskipTests compile`。
- `.playwright-mcp/` 是 71 个浏览器调试运行产物；不参与构建或运行。删除不会影响功能，是否提交删除由用户决定。
- Kotlin 标准库不能整体删除：iLink SDK 经 OkHttp/Okio 传递依赖 Kotlin。Kotlin 插件、`kotlin-test` 与重复编译 execution 仍需在完整构建依赖视角下单独审查，当前不动。
